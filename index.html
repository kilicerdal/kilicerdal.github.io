Recruiter AI Dashboard

Recruiter AI Dashboard is a personal automation application designed to organize recruitment opportunities, analyze job descriptions, and generate job-matching dashboards.

Application Features

  • Organizes recruitment opportunities.
  • Analyzes job descriptions using local AI.
  • Generates job-matching scores and dashboards.
  • Synchronizes authorized dashboard data with Google Sheets.

Privacy and Contact

The application is intended for personal use and is not offered as a public recruitment service.
